Project Title
Password Manager
live demo https://aesencryption.netlify.app/

Course
Security and Assurance

Description
This project is a class assignment for the Security and Assurance course, designed to implement and demonstrate secure practices in password management. The application allows users to securely store, retrieve, and manage their passwords, focusing on encryption and protection against vulnerabilities.

Features
Secure storage of passwords using AES encryption.
User authentication for secure access to the password manager.
Easy retrieval of stored passwords.
Protection against unauthorized access and common security threats.
Objective
To apply security principles learned in the course by developing a robust and secure password manager that adheres to best practices in software security.

Technologies Used
This project utilizes modern web technologies and encryption algorithms to ensure security and reliability in managing sensitive information.
